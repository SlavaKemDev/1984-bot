# 1984-bot
Бот, который сделает из вашего анонмного канала реальный 1984.

## Установка
1. Выполните установку зависимостей:
```bash
pip install -r requirements.txt
```
2. В модуле TelegramBot создайте файл `.env` и добавьте в него переменные окружения:
```
BOT_TOKEN=...
CHANNEL_ID=-100[...]
ADMIN_ID=...
```

ID канала можно получить следующим образов: скопируйте ссылку на любое сообщение из канала, там будет 2 числа: первое - это ID канала, второе - ID сообщения. Припишите к первому числу -100 слева и вставьте в .env файл

Свой ID можно узнать, написав боту [@userinfobot](https://t.me/userinfobot). Его нужно записать в ADMIN_ID

3. Запустите бота:
```bash
python main.py
```

## Использование
1. Добавьте бота в канал
2. Дайте боту права администратора (отправка, удаление и редактирование сообщений)

## Возможности бота
1. Цензура анонимных постов: анонимно можно отправить только текстовые сообщение, медиа будут удаляться. Чтобы отправить медиа анонимно, нужно выполнить следующие действия:
   1. Первый раз написать боту в личные сообщения /start
   2. Принять соглашение о том, что вы не будете постить ничего, что нарушает законодательство РФ
   3. Отправить боту медиа, которое вы хотите отправить анонимно, ваше имя будет сохранено, но нигде не отобразится
   4. Отправить сообщение с вашим медиа в канал (медиа можно отправлять в канал сколько угодно раз)
2. Блокировка конкретных медиа: если админ в ответ на медиа пропишет команду /ban в канале, бот будет удалит все посты с этим медиа и будет удалять их при следующих отправках
3. Антиспам для текстовых сообщений: если пользователь отправляет одинаковое сообщение несколько раз подряд, бот удаляет все сообщения, начиная с определенного количества повторений
4. Блокировка сообщений: прописав команду /mute в канале в ответ на сообщение, бот будет блокировать подобные сообщения всегда
5. Удаление спамных стикеров: бот удаляет все рандомизированные стикеры, которые отправляются в канал (казино, футбол, баскетбол, боулинг, дартс, игральная кость). При этом есть возможность оставить джекпот в казино. Например, если выпало 777, стикер не удаляется
